# MIDI files for trying Import MIDI

Fifteen well-known tunes for **Menu → Import MIDI**, chosen so they can ship with MagSID: the music
is in the public domain, and fourteen files come from the [Mutopia Project](https://www.mutopiaproject.org),
whose music "may be freely downloaded, printed, copied, distributed, modified, performed and recorded".
The Entertainer is R. D. Tennent's arrangement for four recorders, from [IMSLP](https://imslp.org) and
the Werner Icking Music Collection - four separate lines, which suit three SID voices better than a
piano's two hands. The files are their sources' own MIDI renderings, unchanged apart from their names.

Eleven are dedicated to the public domain. Four are under Creative Commons ShareAlike licences, which ask for
credit and that a changed version keeps the same licence. Those credits are below. These files
are not covered by MagSID's own GPL; each keeps the licence listed here.

Every file is imported, exported and played on the emulated 6502 by
`MidiImportExportTests.Every_file_in_midifiles_imports_exports_and_plays`.
